# AI Smart Agriculture Assistant

An AI/ML-Based Smart Decision Support System for Agriculture.

## Technologies

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Python
- FastAPI
- Scikit-learn

## Modules

- Authentication
- Farm Management
- Soil Analysis
- Crop Recommendation
- Fertilizer Guidance
- Irrigation Assistant
- Weather
- Disease Detection
- Prediction History
- Reports
- Admin Dashboard
